Scene Text Editing Research

STELLAR

STELLAR(Scene Text Editing for Low-resource Languages)는 간판과 인쇄물에 존재하는 텍스트를 문맥과 스타일을 유지한 채 교체하는 연구 프로젝트입니다. 저자원 언어에 최적화된 데이터 파이프라인과 Dual-Stream Transformer 기반 편집기로, 기존 영어 중심 모델이 놓치던 레이아웃 보존과 가독성을 개선했습니다.

Problem

현장 간판·포스터를 로컬라이징할 때 글꼴, 음영, 배경 질감을 함께 복원해야 합니다. 공개 데이터는 대부분 영어 스크립트에 편향되어 있어 한국어·베트남어·태국어에서 모델이 쉽게 붕괴됩니다.

Goal

인쇄물 재촬영 없이 텍스트만 교체하여 디자인 팀의 번역 사이클을 단축하고, 저자원 언어에서도 상용 수준의 가독성을 확보하는 편집기를 제공하는 것이 목적입니다.

Outputs

  • Scene text editing 모델 및 학습 코드
  • 언어별 120K synthetic pair 데이터셋
  • 편집 결과 품질 측정 툴킷

Key Contributions

  • Dual-Stream Transformer로 콘텐츠 의미와 스타일 신호를 분리 학습
  • 언어별 폰트 프로파일러 + GAN 기반 배경 보정으로 일관된 합성 데이터 구축
  • 에디터 품질을 빠르게 점검하는 Character Accuracy + CLIP-Text 구조화 지표 정의

Architecture

STELLAR는 Layout Analyzer와 Text Editor 두 모듈로 이루어진 Dual-Stage 파이프라인입니다.

  • Layout Analyzer: Swin-Transformer로 텍스트 영역과 배경 레이어를 분리해 positional prompt 생성
  • Text Editor: Diffusion 기반 Decoder가 새 문자열을 렌더링하고 NeRF-inspired light field로 합성
  • Consistency Feedback: OCR confidence가 낮으면 iterative refinement를 수행

Data & Training

  • 실제 상업 간판 4,200장을 촬영해 배경 도메인을 확보
  • 언어별 문자 통계를 기반으로 12만 개 synthetic pair 생성
  • Text Spotting 모델을 teacher로 사용해 pseudo-label 품질을 관리
  • Edge-aware augmentation과 폰트 morphing으로 미세한 획 차이까지 반영

Deployment

WebAssembly 기반 편집 데모와 ONNX Runtime 경량 모델을 동시에 제공하여, 브라우저에서도 시연이 가능하도록 설계했습니다. API 서버는 TorchServe 위에서 동작하며, 배치 추론 시 GPU 사용률을 40% 절감했습니다.

Results

Baseline 대비 가독성과 스타일 보존 지표에서 모두 향상되었습니다. 자세한 수치는 논문 전문에서 확인할 수 있습니다.

Accuracy Character 인식 기반 품질 지표가 꾸준히 상승했습니다.
Style 레이아웃·폰트 일치도가 기존 baseline 대비 안정적으로 유지됩니다.
Speed 배치 추론 파이프라인 최적화로 처리 지연을 줄였습니다.

디자인팀과의 사용자 스터디에서도 번역·교정 사이클이 체감상 크게 단축되었다는 피드백을 받았습니다.

Project Timeline

2025.03 – 문제 정의

로컬라이제이션 파트너사와 워크숍을 진행하며 주요 사용 시나리오와 품질 기준을 명문화했습니다.

2025.05 – 데이터 파이프라인 완성

촬영 데이터 클리닝 및 Synthetic Generator를 구축해 언어별로 균형 잡힌 코퍼스를 확보했습니다.

2025.07 – 모델 튜닝

Dual-Stream Transformer와 Diffusion Decoder를 결합하고 Iterative refinement 전략을 실험했습니다.

2025.08 – AAAIW 제출

실험, 사용자 스터디, Ablation을 정리해 AAAI Workshop에 논문을 제출하고 공개 페이지를 준비했습니다.
